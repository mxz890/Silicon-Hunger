## 1. 基线

~~~text
baseline = 0.89
~~~

---

## 2. 阈值消融

规则：

~~~text
最近障碍距离 < threshold
→ 专家动作接管
~~~

| threshold | success | steps | triggers |
| ---: | ---: | ---: | ---: |
| 0.00 | 0.89 | 121.08 | 0 |
| 0.10 | 0.89 | 121.08 | 0 |
| 0.20 | 0.89 | 121.08 | 0 |
| 0.30 | **0.92** | 123.26 | 443 |
| 0.45 | 0.85 | 133.34 | 2,572 |
| 0.60 | 0.91 | 125.68 | 6,243 |

总耗时：30.581 s

---

## 3. 结论

> 最优安全阈值是 0.30，2 障碍从 89% 到 92%。

- 阈值 0–0.20：不触发，等于基线
- 阈值 0.30：少量触发，提升到 92%
- 阈值 0.45：触发过多，下降到 85%
- 阈值 0.60：触发更多，回到 91%

所以：

> 安全层不是“越早接管越好”。

最优：

~~~text
threshold = 0.30
triggers = 443 / 100 episodes
~~~
