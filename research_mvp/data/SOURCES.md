# Chinese text sources

The corpus used for the real-text next-character task is extracted from
public-domain modern Chinese stories by Lu Xun (鲁迅, 1881–1936).

| Story | Source |
| --- | --- |
| 狂人日记 | http://www.chinawriter.com.cn/n1/2018/0516/c419384-29994709.html |
| 孔乙己 | http://www.chinawriter.com.cn/GB/n1/2021/0907/c440988-32220179.html |
| 故乡 | https://www.chinawriter.com.cn/n1/2021/0907/c440988-32220174.html |
| 药 | http://www.chinawriter.com.cn/n1/2021/0907/c440988-32220182.html |

The texts are used only for local research experiments. Lu Xun died in
1936; his works are public domain in China and in many other jurisdictions.
The extracted local corpus is stored as luxun_corpus.txt.
